# 🐾 Paws Shelter — Final

A tiny pet adoption website to learn **React Router**.

```bash
npm install
npm run server   # fake API on http://localhost:9000/pets
npm start        # app on http://localhost:3000
```

`src` contains the lesson **and** the challenge solution (marked with `🏆 CHALLENGE` comments). See `CHALLENGE.md`.

Adoptions are saved in `data/db.json` (each adopted pet gets `adopted: true`, `adopter`, `reason`, `adoptedAt`).
